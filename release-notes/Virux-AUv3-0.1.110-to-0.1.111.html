Virux-AUv3 Release Notes

Versions 0.1.110 – 0.1.111

v0.1.111 2026-10-11

  • Device: new Release USB command under Config - System Info - Device, in both AUv3 and VST3, including when only one synth is connected. Virux stops audio capture and MIDI, retires queued MIDI, cancels any running patch sweep and closes its USB interfaces so other compatible software can use the synth, while the editor and the saved project stay available. Choose Reconnect in the same menu to take the synth back.
  • Device: the release preference is per device (keyed by its USB port - a different port means a new key), applies across all Virux instances, the standalone app and the background sync agent, and survives closing the DAW or unplugging the synth. It is never saved into project state, so loading a project does not clear it; Reconnect is always explicit. The sync agents see the marker and defer without counting it as a connection failure. On macOS, releasing frees the vendor USB interfaces but does not install a MIDI driver or guarantee a system MIDI port appears; on Windows it does not change the installed USB driver.
  • Editor: the oscillator displays now draw live, phase-stable preview waveforms. Classic previews follow the selected wave, shape and pulse width; HyperSaw previews follow density and local detune. The displays are larger and are illustrative renderings, not captured hardware audio.
  • Editor: named wave selection now covers the Wavetable, Wave PWM, Grain Simple/Complex and Formant Simple/Complex oscillator models. HyperSaw gains rotary density and local-detune controls plus a single central X-Sync dial, replacing the old text sliders.
  • Browser: drag a patch within an editable bank to move it to the destination row, or onto empty space to move it to the end - no patch is overwritten. This works even when both panes show the same bank, preserves every patch and occupied program slot, switches that bank's panes to program order, and supports Undo last bank edit, MIDI export and project recall. Dragging between different banks still copies. Device banks remain read-only: duplicate one for local editing, and rearranging a draft never writes the hardware banks or overwrites source files.
  • Testing: new coverage for USB release and reconnect across the C API open paths, session engine shutdown ordering, the preference watcher, sync-agent deferral and the device registry's teardown ordering, plus the oscillator preview renderings and browser drag-to-move including undo, export and project recall. 76/76 CTest cases passed on Linux, including full runs under the address/undefined-behavior and thread sanitizers, and the macOS plugin smoke test passed in CI on the release commit.
