Virux-AUv3 Release Notes

Versions 0.1.117 – 0.1.118

v0.1.118 2026-10-17

  • Windows: the standalone app now carries the Virux icon. Virux.exe, its taskbar button and the installer's Start Menu shortcut previously showed the generic Windows executable icon; the app now embeds its own icon at every system size.
  • Linux: the standalone window shows the Virux icon on every desktop, including window managers that do not pair windows with .desktop entries and when running unpacked from the tarball. The desktop entry now names the window class explicitly so launchers group the running window with it.
