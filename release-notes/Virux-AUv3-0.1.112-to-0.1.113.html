Virux-AUv3 Release Notes

Versions 0.1.112 – 0.1.113

v0.1.113 2026-10-13

  • Studio: Morph's four-corner mode is no longer hidden behind the A/B slider (public issue #10). Capturing corner C or D switches the pad to Four corners automatically, and the single toggle is replaced by separate A to B and Four corners buttons so both modes are visible at once; returning to A to B resets the vertical position.
  • Studio: dragging Morph fully to an endpoint now restores that corner exactly (public issue #10). At A, B, C or D the captured values are recalled verbatim within the selected groups, including discrete modes, instead of leaving modes untouched; between endpoints modes stay fixed unless midpoint switching is enabled, and locks still apply. The slider and pad now use the same five-pixel endpoint targets as the marker, so both ends can be reached with a click inside the control.
  • Studio: the Patch Assistant gains a Desktop / MCP provider for Claude Desktop users who do not have Claude Code or the Codex CLI installed (public issue #10). Enable creates a per-user exchange folder, Send publishes the current patch, parameter reference and request there, and a small local MCP server (tools/virux_mcp.py, Python 3.10+, standard library only, bundled under Resources/assistant with a setup guide) lets Claude Desktop list, read and answer pending requests. Replies go through the same proposal validation, Review changes, Apply and Undo flow as the CLI providers; the tools cannot apply edits, touch the synth, run commands or read credentials. Requests expire after ten minutes and Cancel removes them.
  • OsTIrus: firmware discovery now finds a ROM that lives in The Usual Suspects' roms folder (public issue #10). The roms subfolder is scanned before the bounded recursive search so a large preset library can no longer exhaust the scan budget before the firmware is reached, .bin and .rom extensions match case-insensitively, and on Windows the Documents Known Folder (including redirected or OneDrive Documents) is checked ahead of the conventional %USERPROFILE%\Documents path. Explicit saved configurations keep priority and VIRUX_DATA_DIR still disables automatic scanning.
  • Config: the website link on the Config page moved above the System Info card, where it no longer collides with the optional keyboard-routing, driver, diagnostics and preset-folder rows (public issue #10).
  • Device: the Windows button formerly labelled Switch to Access driver... is renamed Remove Virux driver for Access... in all four languages, and its confirmation dialog and README now describe what it does: with every Virus unplugged it stops and disables Patch Sync and removes Virux's WinUSB packages, after which you install or repair the Access suite and restart. A package-preserving in-place switch between the two drivers (public issue #10) is not implemented; it needs a reboot-coordinated handoff validated against the Access driver, and the design for that is documented in the repository.
  • Build: the release workflow's GitHub-release job is now granted the contents:write permission explicitly, since the workflow default is read-only.
  • Testing: new regression coverage for the Morph corner-selection and endpoint-recall behavior, the Desktop assistant exchange worker (cancellation, multiple requests, bounded replies and path restrictions), an MCP stdio client exercising the real server as a subprocess, OsTIrus ROM discovery under a large preset tree, uppercase extensions and the explicit roms folder, and the moved Config website link. On the release code, the Windows native suite passed 88/88 and the MCP Python suite 6/6, with the VST3 SDK validator at 47/47. Still manual: Claude Desktop end-to-end interaction and redirected Documents on the reporter's Windows profile.
